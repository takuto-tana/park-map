# Park Map

## 概要

公園施設案内サイトです。

### 開発経緯
入社した会社でReact,Next.jsの研修の研修の理解のチェックのために作成いたしました。
研修時勉強に行き詰まると浜町公園を散歩しておりその思い出の公園の紹介ページを作ろうと思い作成いたしました。
また浜町公園の雰囲気に合わせあえて「昔の個人サイトを思わせる、懐かしく親しみやすいデザイン」を目指して作成いたしました。

## 使用技術

- Next.js
- React
- TypeScript
- Tailwind CSS

## 機能

- カテゴリナビゲーション
- アコーディオン表示
- 画像スライダー

## 工夫した点

- コンポーネント分割
- TypeScriptによる型定義
- カテゴリごとのスクロール機能
- デザイン(あえて古いサイトに近いページ)
