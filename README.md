# Park Map

## 概要

浜町公園利用者向けの施設案内サイトです。

施設カテゴリごとの一覧表示や詳細情報の確認ができ、利用者が目的の施設を見つけやすいように設計しました。

本プロジェクトは、Next.js・TypeScript・Tailwind CSS の学習を目的として作成しました。

---

## 使用技術

* Next.js
* React
* TypeScript
* Tailwind CSS
* Git / GitHub

---

## 主な機能

### 施設一覧表示

カテゴリごとに施設情報を表示します。

### カテゴリナビゲーション

カテゴリボタンをクリックすると対象カテゴリへスムーズに移動できます。

### アコーディオン表示

施設名をクリックすると詳細情報を表示できます。

### 画像スライダー

複数画像を持つ施設では前後ボタンで画像を切り替えることができます。
